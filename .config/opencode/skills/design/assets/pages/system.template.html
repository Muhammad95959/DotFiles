Design system

__Two sentences: the visual idea behind this system and the three principles that guide every screen.__

Color primitives

Raw ramps. Screens never use these directly, only through the semantic roles below.

Semantic roles

What screens use. Each role shows its value and the primitive it points to, per theme.

Contrast (WCAG 2.2 AA)

Every foreground/background pair the components use. Text needs 4.5:1, large text and UI parts (borders, focus ring, icons) 3:1. Generated by the build, so it can't drift from the tokens.
